# Boardgame Tierlist Maker

A simple web app to create and manage tierlists of your favorite boardgames!

## Features

- 🔍 **Search boardgames** - Search the BoardGameGeek database
- 🖼️ **Game images** - See game artwork and thumbnails
- 📊 **Drag-and-drop tierlist** - Organize games into S, A, B, C, D, F tiers
- 💾 **Auto-save** - Your tierlist is saved to browser storage automatically
- 🗑️ **Easy management** - Remove games or clear the entire list

## How to Use

1. Open `index.html` in your browser
2. Type a boardgame name in the search box and press Enter
3. Click on any game image to add it to your tierlist
4. Drag games between tiers to reorganize them
5. Your tierlist is automatically saved!

## No Installation Required

This is a pure frontend application - just open the HTML file and start using it!

## Technical Details

- **Search API**: BoardGameGeek XML API (CORS proxy)
- **Storage**: Browser localStorage
- **Technology**: Vanilla HTML, CSS, JavaScript (no dependencies)

Enjoy building your tierlist! 🎲
